# 文件管理系统使用指南

## 系统概述
这是一个基于 Spring Boot + MinIO 的文件管理系统，支持文件上传、下载、分享、用户管理等功能。

## 主要功能

### 1. 存储桶管理
- 查看所有存储桶
- 创建新的存储桶
- 删除存储桶
- 管理存储桶中的文件

### 2. 文件管理
- 上传文件（支持拖拽）
- 下载文件
- 删除文件
- 创建文件夹
- 文件预览
- 文件分页浏览
- 文件排序（按名称、大小、时间）

### 3. 文件分享
- 创建分享链接
- 设置分享有效期
- 设置分享密码
- 查看分享列表
- 取消分享

### 4. 用户管理（管理员）
- 查看用户列表
- 创建新用户
- 编辑用户信息
- 分配用户角色
- 启用/禁用用户
- 删除用户

### 5. 角色管理（管理员）
- 查看角色列表
- 创建新角色
- 编辑角色信息
- 配置角色权限
- 删除角色

### 6. MinIO 密钥管理（管理员）
- 创建 MinIO 访问密钥
- 配置密钥权限
- 设置密钥有效期
- 查看密钥列表
- 删除密钥

### 7. 系统配置（管理员）
- 配置允许上传的文件类型
- 配置最大文件大小（-1表示无限制）
- 配置批量分享/下载大小限制
- 配置分享链接有效期

## 使用说明

### 上传文件
1. 点击"上传文件"按钮
2. 选择文件或拖拽文件到上传区域
3. 点击"上传"按钮

### 创建文件夹
1. 点击"新建文件夹"按钮
2. 输入文件夹名称
3. 可选：勾选"创建测试文件"
4. 点击"创建"按钮

### 分享文件
1. 勾选要分享的文件
2. 点击"分享"按钮
3. 设置有效期和密码（可选）
4. 点击"创建"按钮
5. 复制分享链接给他人

### 批量下载
1. 勾选要下载的文件
2. 点击"批量下载"按钮
3. 系统会自动打包成ZIP文件下载
