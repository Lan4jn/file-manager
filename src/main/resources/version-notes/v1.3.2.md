# v1.3.2 版本更新内容

## 功能优化

### 1. 文件列表分页体验优化
- ✅ 默认按名称升序时，优先展示目录，再展示普通文件
- ✅ 采用“先识别目录、再补齐当前页文件”的分页策略
- ✅ 避免为了目录优先而一次性加载整个目录下的全部文件
- ✅ 兼顾大目录场景下的可用性与分页响应速度

### 2. 地址栏交互增强
- ✅ 地址栏支持更接近 Windows 资源管理器的操作方式
- ✅ 支持点击空白区域进入编辑态
- ✅ 支持 `Ctrl + L` 快速选中并编辑当前路径
- ✅ 优化根目录与面包屑路径展示

### 3. HTTP / HTTPS 访问提示优化
- ✅ 新增独立 HTTP 端口用于访问提示页
- ✅ 通过 HTTP 打开页面时，顶部显示蓝色提示条
- ✅ 提供“点此跳转”链接，快速切换到 HTTPS

## Bug 修复

### 4. 目录与文件名称显示修复
- ✅ 修复目录对象显示为完整路径的问题
- ✅ 目录名称改为只显示最后一级名称
- ✅ 修复部分分页场景下目录未优先展示的问题
