# v1.7.1 版本更新内容

## 文件管理能力增强

- 新增当前桶内的文件和目录移动能力，支持单个项目和批量项目统一操作。
- 新增当前桶内的文件和目录复制能力，支持单个项目和批量项目统一操作。
- 移动/复制在执行前会先进行目标目录合法性和同名冲突检查，避免直接落盘后才报错。
- 冲突处理支持覆盖或自动重命名共存，降低批量整理文件时的中断概率。

## 文件列表操作优化

- 文件列表单行操作支持按配置收纳到“更多”菜单，缓解按钮过多导致的拥挤问题。
- 可收纳操作统一补齐图标和文字标签，主操作区与“更多”菜单保持一致。
- 行内操作按钮样式回退到旧版尺寸与视觉，保留原先更紧凑的操作体验。

## 上传与列表交互修复

- 修复上方框选上传后，文件未出现在上传窗口、也未实际上传的问题。
- 修复上传完成后的临时条目在关闭上传窗口后仍残留显示的问题。
- 修复拖拽上传、上传完成撤销和“信息同步中”状态相关的显示缺口。

## 移动/复制窗口修复

- 修复移动/复制窗口“返回上级”无效的问题。
- 目录选择窗口现在只展示目录项，并在非根目录下显示 `..` 作为上级目录入口。
- 目录切换、返回上级和选择当前目录统一使用同一套状态逻辑，减少跳转错乱。

## 稳定性与兼容性修复

- 修复移动/复制预检查未校验源路径和目标目录存在性的问题。
- 修复批量传输失败时可能留下部分成功结果或空目录残留的问题，改为失败即回滚。
- 修复文件传输服务在 Spring 启动时因多构造器选择不明确导致的 Bean 创建失败问题。
- 持续完善特殊字符文件名、排序、分页与版本说明展示等细节体验。
