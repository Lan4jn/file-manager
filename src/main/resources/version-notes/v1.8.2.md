# v1.8.2 版本更新内容

## 工作台体验修复

- 修复默认进入工作台时未预加载桶列表的问题，登录后首次点击“文件管理”即可看到可访问桶。
- 工作台提醒摘要中的分享提醒支持点击，带分享码的提醒会直接打开对应分享空间。
- 当提醒缺少分享码时，会回退打开消息中心收件箱，方便继续处理对应分享消息。
- 应用代理上传在 `putObject` 成功后不再因 `statObject` 暂时不可见而判定失败，会保留 WARN 日志供排查。
- 收件箱列表新增分享内容展示，可直接看到收到的文件/目录摘要。
- 工作台分享提醒点击会通过站内信打开分享，确保跳转后同步标记已读。
- 工作台欢迎信息上移到页头，移除空白欢迎卡片以提升空间利用率。
