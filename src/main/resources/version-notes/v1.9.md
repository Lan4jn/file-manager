# v1.9 版本更新内容

## build152

- 将工作台的「最近访问目录」与「收藏目录」拆分为上下两张独立卡片，新增图标徽章与数量胶囊。最近目录在宽屏上采用紧凑双列，收藏目录保留整行清单，并以暖琥珀色星标和顶部强调线区分。
- 根据新版 `favicon.svg` 重新生成包含 32×32 和 64×64 尺寸的透明 `favicon.ico`，并更新主页面与分享页的图标缓存参数，避免浏览器标签页继续显示旧图标。

## build151

- 修复系统配置权限错位，并在前端显示后端返回的具体错误信息。
- 将全站系统图标与 favicon 更新为极简层叠档案夹风格，适配浅色和深色主题。

## build150

- 为 `index.html` 补充 `v-cloak` 与内联首屏防闪样式，避免刷新时暴露未编译模板，并消除深色模式下的闪白。
- 为 `share.html` 同步补充首屏浅色和深色底色，避免加载时闪烁。

## build149

- 大文件上传经应用代理接入 MinIO 原生分片上传：分片通过 64 KB 缓冲区流式转发，应用服务端不写临时文件；全部分片上传后由 MinIO 合并。
- 分片上传支持断点续传，恢复时仅补传缺失分片；跨任务实施全局分片并发限流。取消上传会清理未完成分片，后台定期清理会话过期（默认 24 小时）留下的孤儿分片。
- 下载会话默认有效期（TTL）延长至 60 分钟。下载过程中遇到链接过期时，前端自动续签并从当前断点继续。
- 支持直接写入本地文件的浏览器可按 16 MB 分段下载并流式写盘，无需将整个文件缓存在内存中。
- 归档 ZIP 下载支持 HTTP Range 请求，返回 `206 Partial Content`，可从中断位置继续下载。
- 工作区右下角新增独立于消息中心的统一传输面板，集中显示上传和下载任务的进度、速率、分片状态及可用操作。

## build148

- 为工作台和分享页新增低对比度、淡雅的建筑光影背景图，随浅色和深色主题切换。
- 移除主内容区 1440px 的宽度上限，优化双栏工作台、设置表单和分享页在 1920px 以上宽屏及 4K 显示器上的响应式布局，让内容充分利用可用宽度。
