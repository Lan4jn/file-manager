# v1.4 版本更新内容

## 核心升级

### 1. 权限体系升级为完整 RBAC
- 新增基于角色的菜单权限、接口权限、存储桶权限控制
- 支持一个用户绑定多个角色，权限按角色聚合生效
- 新增“当前用户权限信息”接口，用于前端动态控制菜单和按钮显示
- 超级管理员规则加强：唯一、不可删除、不可降权，系统配置仅超级管理员可用

### 2. 角色管理能力补齐
- 角色支持独立配置菜单权限、接口权限和存储桶权限
- 存储桶权限改为表格化管理，支持逐条启停、逐条编辑和批量删除
- 支持“所有存储桶”和“所有权限”通配规则
- 支持单桶权限覆盖全桶权限，保证更细粒度规则优先生效

### 3. 用户管理和个人中心增强
- 用户管理支持管理员创建用户、编辑用户信息、分配多角色
- 管理员现在可以直接修改用户密码
- 右上角个人信息菜单补齐了资料编辑和密码修改功能

## 文件与分享体验优化

### 4. 文件浏览和路径交互优化
- 地址栏改为更接近资源管理器的交互方式，支持点击进入编辑和快捷键编辑
- 文件分页与目录优先显示策略进一步优化，兼顾大目录场景的响应速度
- 目录名称显示修复为只展示最后一级名称

### 5. 分享和访问控制增强
- 分享管理与访问逻辑继续拆分收口，权限控制接入统一断言
- 无权限访问菜单时前端隐藏入口，直接访问地址或接口时会明确提示无权限
