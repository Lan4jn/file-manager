# v1.8 版本更新内容

## 工作台首页

- 左侧导航新增“工作台”，支持作为登录后的默认首页。
- 工作台集中展示最近访问目录、收藏目录和最新分享提醒，减少频繁切换模块的成本。
- 最近访问目录会随着成功进入目录自动更新，重复访问会刷新时间而不是生成重复记录。

## 目录历史与收藏

- 新增目录历史能力，可快速回到最近操作过的目录。
- 新增收藏目录能力，支持在文件管理页直接收藏当前目录，也支持在工作台内取消收藏。
- 最近访问与收藏目录并列展示，常用入口更稳定。

## 分享提醒增强

- 创建分享成功后会实时弹出横幅提醒，立即反馈分享结果。
- 收到别人分享的文件后会实时显示横幅提醒。
- 工作台会同步汇总最近的分享提醒，方便回看。

## 文件操作增强

- 新增文件和目录重命名功能，支持同目录内直接改名。
- 同名冲突时支持覆盖或自动重命名，减少整理文件时的中断。
- 上传前支持修改目标文件名，并提供前缀、后缀、查找替换三种批量改名方式。

## 兼容性与稳定性修复

- 补齐重命名、上传改名、工作台偏好等前后端闭环逻辑。
- 修复分享提醒、目录收藏、默认首页切换等场景中的状态同步问题。
- 持续完善批量操作、目录切换和版本说明展示等细节体验。
