# v1.7-dev 版本更新内容

## v1.7-B 消息中心基线

- 新增站内分享收件箱，支持分享创建时指定系统用户作为接收方。
- 收件箱支持未读状态展示、已读标记与删除操作。
- 分享列表新增“发给我的”视图，便于统一处理站内分享。
- 分享创建界面支持在链接分享和指定用户分享之间切换。

## 下载链路增强

- 下载逻辑统一收敛到 `transfer` 模块，便于区分应用直连、代理流式下载和归档任务下载。
- 批量下载与目录下载改为归档任务模式，前端通过轮询任务状态再触发下载。
- 大文件分块下载增加完整性校验，降低文件尾部损坏风险。
- 分享归档任务在服务重启后可基于持久化上下文恢复执行。
- 新增 `DIRECT` 直连下载模式，可返回 MinIO 预签名 GET URL，由浏览器直接下载对象。
- 大文件下载优先尝试浏览器“边读边写磁盘”，失败后退到浏览器原生下载，最后才回落到前端内存分块拼装。
- 修复 `DIRECT` 下载回退与大文件浏览器接管状态显示，避免应用下载链路误报成功。

## 上传链路增强

- 新增上传会话接口，支持按配置切换“后端代理上传”和“MinIO 预签名 PUT 直传”。
- 直传上传完成后会回调业务侧确认接口，补齐对象元信息并保持现有文件列表展示逻辑。
- 修复直传上传确认失败后的错误回退，避免对象已写入后再次重复上传。
- 优化上传失败提示，前端会优先显示后端返回原因、HTTP 状态或网络错误，不再只显示“上传失败”。
- 上传失败提示进一步细分为权限不足、文件过大、类型不允许、对象存储异常、确认失败等分类。
- 上传完成提示改为右上角非阻塞通知，支持直接撤销本次上传。

## 文件列表修复

- 修复目录修改时间缺失时错误显示为当前时间的问题，改为按真实时间展示，缺失时显示为空。
- 兼容旧版 MinIO `lastModified` 字段缺失场景，避免文件列表因空时间直接抛异常。
