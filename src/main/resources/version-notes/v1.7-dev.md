# v1.7-dev 版本更新内容

## v1.7-B 消息中心基线

- 新增右下角消息中心入口，保留左侧“我的分享”未读提醒。
- 支持在消息中心内查看收到的分享消息，并执行打开、转发、标记已读、删除。
- 新增“我要反馈”页签，普通登录用户可直接提交 BUG 与建议反馈。
- 消息中心接入 WebSocket 推送，分享消息与反馈消息可实时刷新。

## 分享转发增强

- 用户可将自己收到的站内分享再次转发给其他用户。
- 转发会重新生成新的用户分享记录和新的分享码，不复用旧分享码。
- 转发链路展示“初始分享人”和“当前转存人”，不继续展开更早的中间链路。

- 当前分支版本号已切换为 `1.7-dev`。
