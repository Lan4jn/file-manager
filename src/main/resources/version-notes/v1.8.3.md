# v1.8.3 版本更新内容

## 工作台提醒摘要增强

- 修复默认角色缺少存储桶通配权限导致文件下载返回 403 的问题。
- 修复下载会话返回受保护应用下载地址，以及直连失败时未回退代理流地址的问题。
- 新增前端诊断面板，记录 HTTP 错误、下载会话、直连回退和浏览器脚本异常。
- 新增达梦数据库 Maven profile、独立运行配置、SQLite 数据迁移工具和条件集成测试入口。
- 归档任务、审计详情和站内消息正文改用 CLOB 映射，兼容达梦长文本存储。
- 新增动态镜像数据源，业务始终读写主库，事务提交后同步多个镜像库并定时执行主库权威校准。
- 新增镜像同步状态和手动同步接口，镜像故障不会阻止主库继续提供服务。
- 提醒摘要标题右侧新增未读气泡，快速查看未读分享数量。
- 分享提醒条目右侧新增分享内容摘要，可直接识别收到的文件或目录。
- Log4j2 配置内置到 jar 包，默认不再依赖外部 `config/log4j2.xml`。
- HTTPS 仅启用 TLS 1.2/1.3 与 ECDHE/TLS 1.3 AEAD 套件，禁用 DHE 套件以修复瞬时 Diffie-Hellman 密钥过弱风险。
