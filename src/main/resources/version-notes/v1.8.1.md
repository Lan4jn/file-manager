# v1.8.1 版本更新内容

## 分享管理优化

- 我的分享列表新增“分享内容”列，分享文件和目录可直接在表格中查看。
- 分享内容标签支持鼠标悬停查看对象存放路径。
- 分享到用户时，分享方式会直接显示具体接收用户。
- 删除分享记录和取消分享拆分为两个动作，避免误删导致分享失效。

## 兼容性修复

- 已取消分享在访问、校验、下载和内容列表入口统一提示“分享已取消”。
- 旧分享记录默认保持有效和可见，升级后不影响原有分享访问。
- 直传上传完成后若对象存储确认提示对象不存在，会自动回退为应用代理上传，减少大文件上传误失败。
- 直传上传完成确认阶段会对对象暂不可见进行后端重试，降低大文件刚上传完成时 `statObject` 误失败概率。
- 应用代理上传完成后的对象确认也加入重试，并兼容更多对象不存在错误文案，进一步降低大文件偶发上传失败。
- 上传流程增加 `uploadTraceId` 诊断日志，覆盖前端阶段、会话创建、直传确认、代理上传和对象确认重试，便于排查偶发失败。
