# v1.6 版本更新内容

## 版本定位

v1.6 是围绕“分享能力完善、权限边界补齐、审计可追踪、前端交互可用性提升”完成的一次正式版本发布。

## 分享能力升级

- 新增“分享到用户”模式，文件、目录和批量分享可直接投递到指定用户的站内收件箱。
- 分享中心新增收件箱视图，支持查看、打开、标记已读和删除收到的分享。
- 分享链接默认自动生成 4 位提取码，用户可手动修改，也可清空后发布为公开链接。
- 我的分享支持两种复制方式：
  - 复制说明式链接
  - 复制带提取码链接
- 分享访问链接统一为 `/share/{shareCode}` 形式，带提取码时可直接通过 `?password=xxxx` 访问。
- 分享空间支持目录浏览、按当前层级查看内容，并保留更清晰的路径展示。
- 分享批量下载与目录下载的 ZIP 结构进一步修正，减少系统原生解压异常和空占位文件问题。

## 预览与文件体验改进

- 在线预览支持范围扩展到更多文本类文件，包括 `yml`、`yaml`、`properties`、`sql`、`json`、`xml` 等。
- 文件预览改为站内弹窗，不再额外新开独立网页窗口。
- 预览入口增加类型限制和大文本保护，避免不支持或体积过大的文件直接压垮页面。
- 预览说明改成按“类型（扩展名）”展示，支持范围更直观。
- 预览弹窗增加“可预览文件”提示与悬浮说明，便于用户快速判断文件是否支持在线查看。

## 权限与安全增强

- 权限模型补充并收口：
  - 审计日志菜单权限 `MENU_AUDIT_LOG`
  - 审计日志读取接口权限 `API_AUDIT_LOG_READ`
- 审计日志权限已纳入角色授权体系，可单独配置审计角色。
- 上传弹窗配置读取从超管配置接口拆分，普通具备文件操作权限的用户不再因打开上传框而先收到 403。
- 登录链路继续强化密文传输与挑战响应校验，避免直接明文提交密码。
- 增加密码错误次数限制、账户封禁状态展示、解封时间展示和原生超级管理员手动解封能力。

## 审计与运维能力

- 新增审计日志页面，可查询文件、分享等关键业务操作。
- 审计日志体系与业务权限打通，避免默认向普通用户暴露敏感操作记录。
- README 与部署文档同步更新到 Spring Boot 3 / Java 17 基线。
- Jar 与 Docker 部署文档统一按 `v1.6` 正式版产物说明。

## 交互与界面修复

- 地址栏导航交互修复，可编辑、可回车跳转，并修正相关前端报错。
- 登录页支持回车触发登录。
- “我的分享”菜单与收件箱增加未读提醒，提升站内分享可见性。
- 预览、分享、权限编辑等多个细节交互做了可用性修正。
- 对不符合 Amazon S3 命名规范的旧桶改为给出禁用提示，而不是静默失败。

## 兼容性与底层升级

- 项目整体运行基线已迁移到 Spring Boot 3 与 Hibernate 6 体系。
- SQLite 方言、配置加载和版本说明展示链路已同步适配新版本运行环境。
- 继续保留完整版 / 轻量版双界面模式，并支持通过 YAML 配置切换。
