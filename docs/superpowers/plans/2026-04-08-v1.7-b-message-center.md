# v1.7-B Message Center Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the `1.7-B` message center with real-time WebSocket delivery, feedback submission, and user-share forwarding while preserving the existing `有X人分享给你` reminder.

**Architecture:** Extend the existing `UserShareMessage` model into a lightweight message record, keep `ShareLink` as the authoritative share carrier, create a new `ShareLink` for each forward, and push message events over a user-scoped WebSocket channel. The left sidebar keeps the existing aggregated share reminder while the new bottom-right panel becomes the real-time message entry point.

**Tech Stack:** Spring Boot 3, Spring WebSocket, Spring Security, JPA/Hibernate, Vue 3, Element Plus, Node built-in test runner, JUnit 5, MockMvc
