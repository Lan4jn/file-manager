# 文件移动复制与操作按钮可见性设计

## 背景

当前系统文件列表已经支持上传、下载、分享、删除、预览等能力，但还缺少以下两类基础文件管理能力：

1. 文件/目录的移动与复制，且需要同时支持单个项目与批量项目。
2. 随着按钮继续增加，文件列表单行操作区已经趋于拥挤，需要引入“更多”收纳，并允许管理员通过系统配置调整默认收纳的按钮。

本设计只覆盖“当前桶内不同目录”的移动与复制。跨桶移动/复制明确留到后续版本，不在本次范围内。

## 目标

### 功能目标

- 支持当前桶内单个文件/目录移动。
- 支持当前桶内单个文件/目录复制。
- 支持当前桶内批量文件/目录移动。
- 支持当前桶内批量文件/目录复制。
- 支持在执行前预检查目标目录合法性与同名冲突。
- 支持冲突后二次选择：
  - 覆盖
  - 共存（自动重命名）
  - 取消
- 单行操作区默认收起 `删除`、`移动`、`复制` 三个按钮。
- 管理员可在系统配置中调整哪些单行按钮默认收起。

### 体验目标

- 单个与批量操作走同一套交互和同一套后端模型。
- 目标目录选择过程明确显示当前桶、目标路径、作用对象摘要。
- 不引入“剪贴板式粘贴”状态，避免额外全局状态复杂度。
- 收纳后的操作仍然可发现，不牺牲常用操作效率。

## 非目标

- 不支持跨桶移动或复制。
- 不实现“最近目标目录”“收藏目标目录”“粘贴板模式”。
- 不实现复杂的逐条冲突交互向导。
- 不新增独立的移动/复制权限码，本次沿用现有文件操作权限。

## 用户场景

### 单个项目

- 用户在文件列表某一行点击 `移动` 或 `复制`。
- 系统弹出目标目录选择弹窗。
- 用户选择当前桶内某个目录作为目标路径。
- 系统先做预检查。
- 若有冲突，用户选择“覆盖”或“共存”。
- 系统执行并刷新列表。

### 批量项目

- 用户勾选多个文件/目录。
- 在顶部批量操作区点击 `批量移动` 或 `批量复制`。
- 系统弹出与单个项目相同的目标目录选择弹窗。
- 用户选择目标目录并确认。
- 系统对整批项目执行统一预检查和执行。

### 操作收纳

- 用户浏览文件列表时，单行默认只看到高频按钮，如下载、分享、预览。
- `删除`、`移动`、`复制` 默认出现在 `更多` 下拉菜单中。
- 超级管理员可在系统配置中调整默认收纳项。

## 方案概览

采用一套统一的“文件传输操作”模型：

- 前端统一使用“目标目录选择弹窗”。
- 后端统一提供：
  - 预检查接口
  - 执行接口
- 单个与批量仅在 `sources` 数量上不同，数据结构和执行流程相同。
- 现有 `/api/file/copy`、`/api/file/move` 保留兼容，不作为本次新前端主流程入口。

## 前端设计

### 文件列表单行操作

默认直接显示的按钮保留为高频操作：

- 下载
- 分享
- 预览（仅支持预览的文件显示）

默认收纳到 `更多` 下拉菜单：

- 删除
- 移动
- 复制

下拉菜单项仍然遵循现有权限与文件类型约束：

- 无权限则不显示。
- 不适用的操作不显示。

### 批量操作区

在文件列表顶部批量操作区新增：

- 批量移动
- 批量复制

批量操作区不进入 `更多`，直接显示。

原因：

- 顶部区域空间更充足。
- 批量操作语义需要明显。
- 单行拥挤问题主要出现在表格操作列，而不是顶部工具条。

### 目标目录选择弹窗

弹窗统一用于移动与复制，包含：

- 操作类型标题：移动或复制
- 作用对象摘要
  - 单个时显示文件/目录名
  - 批量时显示“已选择 N 个项目”
- 当前桶名
- 当前选中的目标路径
- 目录浏览区（仅展示目录）
- 返回上级目录
- 进入子目录
- “选择当前目录”并确认执行

约束：

- 只允许选择当前桶内目录。
- 不展示文件作为目标项。
- 目标目录为空时表示桶根目录。

### 冲突交互

前端先调用预检查接口：

- 无冲突：直接执行。
- 有冲突：弹出确认框，给用户三个选择：
  - 覆盖
  - 共存
  - 取消

其中“共存”含义为自动重命名，命名规则由后端统一保证。

### 操作按钮可见性配置

在系统配置页新增一组文件列表单行操作收纳配置。

建议数据模型：

- `fileRowHiddenActions: string[]`

本次支持的枚举值：

- `DELETE`
- `MOVE`
- `COPY`
- `DOWNLOAD`
- `SHARE`
- `PREVIEW`

默认值：

- `DELETE`
- `MOVE`
- `COPY`

解释：

- 该配置表示“默认收纳到更多”的按钮集合，而不是禁用按钮。
- 按钮权限仍由现有 RBAC 控制。

## 后端设计

### 新接口

新增统一预检查与执行接口：

- `POST /api/file/transfer/preview`
- `POST /api/file/transfer/execute`

### 请求模型

统一请求结构：

```json
{
  "operation": "MOVE",
  "bucket": "file-manager",
  "sources": [
    "a.txt",
    "docs/"
  ],
  "targetFolder": "archive/2026/",
  "conflictPolicy": "OVERWRITE"
}
```

字段说明：

- `operation`: `MOVE` 或 `COPY`
- `bucket`: 当前桶
- `sources`: 源对象路径列表
- `targetFolder`: 目标目录路径，可为空表示根目录
- `conflictPolicy`: `ASK`、`OVERWRITE`、`RENAME`

说明：

- `preview` 阶段主要使用 `ASK`
- `execute` 阶段使用 `OVERWRITE` 或 `RENAME`

### 预检查返回

预检查应至少返回：

- 目标目录是否合法
- 是否存在冲突
- 冲突项列表
- 预估目标名称列表
- 是否存在非法移动场景

典型非法场景：

- 源目录移动到自身目录
- 源目录移动到自身子目录
- 源路径不存在
- 目标目录不存在或不可访问
- 批量操作中某项非法

### 执行返回

执行结果建议返回汇总信息：

- 成功数量
- 失败数量
- 失败明细
- 实际重命名结果（若选择共存）

这样前端可以一次性提示，而不是只给出单句“操作失败”。

## 服务层设计

新增统一服务，例如 `FileTransferService`，负责：

- 路径规范化
- 目标路径拼装
- 冲突检查
- 目录自引用校验
- 批量执行编排
- 调用现有 `FileCommandService`

现有 `FileCommandService` 的定位不变：

- 继续承担单个对象或目录树的底层复制/移动动作

新增统一服务的原因：

- 单个与批量的规则集中
- 冲突处理逻辑不散落在 controller
- 后续扩展跨桶时可以在同一层追加源/目标桶权限与路径策略

## 路径与冲突规则

### 目标路径拼装

- 若目标目录为根目录，则目标对象名为原始文件名/目录名。
- 若目标目录非根目录，则目标对象名为 `targetFolder + 原始名称`。

### 同名冲突

- `OVERWRITE`：目标已存在则覆盖。
- `RENAME`：目标已存在则自动生成新名称。

### 共存命名规则

建议采用常见形式：

- 文件：`name(1).ext`
- 目录：`folder(1)/`

同名继续递增：

- `name(2).ext`
- `folder(2)/`

### 非法移动规则

- 文件移动到原位置：视为无实际变更，直接拦截。
- 目录移动到原位置：直接拦截。
- 目录移动到自己的子目录：直接拦截。
- 复制到原位置允许，但若同名则必须依赖覆盖或共存策略。

## 权限设计

本次不新增新权限码，继续沿用：

- `API_FILE_OPERATE`
- 对应桶的文件操作权限

因为当前版本只允许当前桶内操作，所以源与目标桶一致，不需要单独拆分“源读取”和“目标写入”权限。

## 审计与日志

建议将以下信息纳入操作日志：

- 操作类型：复制/移动
- 桶名
- 源项目数量
- 目标目录
- 冲突策略
- 成功/失败结果

若当前审计切面已能覆盖 controller，可优先复用；否则至少保证 service 层有日志记录。

## 错误处理

前端提示应区分：

- 目标目录非法
- 目录不可移动到自身子目录
- 存在同名冲突
- 部分成功部分失败
- 权限不足

后端不应返回泛化的“操作失败”，应保留明确错误语义。

## 测试策略

### 后端

- 单文件复制到新目录
- 单文件移动到新目录
- 批量复制到新目录
- 批量移动到新目录
- 目录复制
- 目录移动
- 同名覆盖
- 同名共存重命名
- 移动到原目录拦截
- 目录移动到自身子目录拦截

### 前端

- 单行 `更多` 菜单渲染
- 系统配置决定哪些按钮默认收起
- 单个/批量弹窗摘要显示正确
- 冲突后出现覆盖/共存/取消选择
- 批量操作按钮可见性

## 实施顺序建议

1. 后端统一请求模型与预检查接口
2. 后端统一执行接口与服务层
3. 前端单个/批量弹窗接入
4. 单行 `更多` 收纳
5. 系统配置项与配置页接入
6. 回归测试与帮助文档更新

## 风险与后续扩展

### 当前风险

- 目录递归复制/移动对大目录会增加执行时长。
- 批量冲突明细过多时，前端提示需要控制可读性。
- 覆盖策略若不先预检查，可能导致用户误操作。

### 后续扩展点

- 跨桶移动/复制
- 最近目标目录
- 收藏目标目录
- 剪贴板式“复制到 / 粘贴”
- 更细粒度的源读/目标写权限模型
