# v1.8.1 Share Management Design

## Overview

v1.8.1 聚焦“我的分享”列表的信息可读性和分享生命周期管理。当前列表中分享内容只在展开行里显示，且“分享到用户”只显示抽象类型，不显示实际接收人；右侧删除按钮实际会删除分享链接，语义更接近“取消分享”，缺少“只删除我的列表记录”的能力。本次设计将这三处拆清楚：主表直接展示分享内容、站内分享展示接收用户、删除记录与取消分享分离。

## Goals

- 将分享内容移动到主表列，放在分享码之后、分享时间之前。
- 分享内容标签悬停时显示对象存放位置。
- 分享到用户时直接展示具体接收用户。
- 明确区分“删除分享记录”和“取消分享”。
- 保持现有链接分享、站内信、分享页下载链路兼容。

## Non-Goals

- 不重做“我的分享”整体页面视觉。
- 不新增分享记录回收站或恢复能力。
- 不修改收件箱消息删除语义。
- 不新增接收人编辑能力。
- 不改变分享码、提取码、分享页 URL 规则。

## Current Behavior

- `我的分享` 表格展示文件名、分享方式、分享码、分享时间、过期时间、访问方式、浏览次数和操作。
- 分享内容位于展开行右侧，用户需要展开才能看到。
- 批量分享内容通过 `/api/share/items` 加载；单文件分享不额外加载列表。
- 分享方式中 `USER` 显示为“分享到用户”，没有具体用户信息。
- 右侧删除按钮调用 `/api/share/delete`，当前后端会删除 `ShareLink`，导致分享失效。

## User Experience

### 分享内容列

主表新增一列 `分享内容`，位置为：

1. 文件名
2. 分享方式
3. 分享码
4. 分享内容
5. 分享时间
6. 过期时间
7. 访问方式
8. 浏览次数
9. 操作

展示规则：

- 单文件分享：显示一个标签，例如 `文件 / report.pdf`。
- 单目录分享：显示目录标签，例如 `目录 / 20260506`。
- 批量分享：显示前 3 个内容标签，例如 `文件 / a.txt`、`目录 / docs`、`文件 / b.jpg`。
- 超过 3 个：追加 `+N` 标签，表示还有 N 个内容未直接展示。
- 加载中：显示 `正在加载...`。
- 加载失败：显示 `加载失败`，不阻塞整张分享列表。

标签视觉沿用当前浅色 `el-tag` 风格：目录使用 `warning`，文件使用 `info`。不做成按钮，不引入新的大尺寸控件。

### 路径悬停提示

每个分享内容标签增加 tooltip：

- 单文件：悬停显示完整对象路径，例如 `bucket-a/docs/report.pdf`。
- 目录：悬停显示目录对象路径，例如 `bucket-a/docs/20260506/`。
- 批量分享：每个标签显示各自对象路径。
- `+N` 标签：悬停显示剩余对象的简要列表，最多展示合理数量，避免 tooltip 过长。

路径来源：

- 优先使用后端返回的 `objectName`。
- 前端展示时拼接 `bucket / objectName`，如果 bucket 为空则只显示 objectName。
- 不从显示名反推路径，避免特殊字符或同名文件造成误判。

### 分享到用户展示

`分享方式` 列在 `targetType = USER` 时显示为：

- 单个用户：`分享给：张三(zhangsan)` 或 `分享给：zhangsan`。
- 多个用户：`分享给：张三(zhangsan)、李四(lisi)`。
- 用户不存在或历史数据缺失：保底显示 `分享到用户`。

展开行中也显示 `接收用户` 字段，展示完整接收人文本。

### 展开行

展开行不再重复展示“分享内容”块，避免主表和详情重复。展开行保留元信息：

- 分享方式
- 接收用户
- 分享链接
- 提取码
- 分享时间
- 过期时间
- 访问方式
- 浏览次数
- 分享状态

### 操作按钮

右侧操作区拆成两个动作：

- `删除记录`：只从创建者的“我的分享”列表隐藏，不影响链接或站内信继续访问。
- `取消分享`：让分享失效，接收人和链接访问统一提示“分享已取消”。

按钮行为：

- 链接分享仍保留复制按钮。
- 站内分享仍显示站内信投递标识。
- 删除图标 tooltip 改为 `删除分享记录`。
- 新增 `取消分享` 按钮，已取消记录不再显示该按钮。
- 已取消记录如果仍未被删除记录，应显示状态 `已取消`。

## Backend Design

### ShareLink 状态字段

`ShareLink` 增加两个字段：

- `hiddenByCreator`：创建者是否已删除列表记录。
- `cancelled`：分享是否已被取消。

兼容旧数据：

- `null` 按 `false` 处理。
- 升级后旧分享默认可见且有效。

### 列表查询

`GET /api/share/list` 只返回当前创建者且 `hiddenByCreator != true` 的记录。

列表返回对象增加临时展示字段：

- `recipientDisplayText`：站内分享接收用户显示文本。

接收用户来源：

- 根据 `shareCode` 查询 `UserShareMessage`。
- 取 `recipientUserId` 反查 `User`。
- 用昵称和用户名生成文本。
- 去重并保持站内信创建顺序。

### 删除分享记录

复用当前 `/api/share/delete`，但语义调整为删除记录：

- 校验当前用户为创建者。
- 设置 `hiddenByCreator = true`。
- 不删除 `ShareLink`。
- 不删除 `ShareFileRecord`。
- 不删除 `UserShareMessage`。

这样接收人仍可通过站内信打开分享，外部链接也保持有效。

### 取消分享

新增 `POST /api/share/cancel`：

- 参数：`shareCode`。
- 校验当前用户为创建者。
- 设置 `cancelled = true`。
- 分享访问、校验、下载、内容列表等入口统一走有效性校验，因此取消后全部失效。

错误文案统一为：`分享已取消`。

## Frontend Design

### 数据加载

分享列表加载后：

- 单文件分享立即生成一个虚拟内容项。
- 目录分享和批量分享异步调用现有 `/api/share/items`。
- 为避免列表初始渲染卡顿，分享内容加载不阻塞主列表展示。

每条分享维护：

- `shareItems`
- `shareItemsLoaded`
- `shareItemsLoading`
- `shareItemsError`
- `visibleShareItems`
- `hiddenShareItemCount`

### 内容展示

前端渲染逻辑：

- `visibleShareItems = shareItems.slice(0, 3)`。
- `hiddenShareItemCount = Math.max(shareItems.length - 3, 0)`。
- tooltip 内容由 `bucket` 和 `objectName` 生成。

### 操作交互

删除记录：

- 确认文案：`确定要删除这条分享记录吗？删除记录不会取消已发出的分享。`
- 成功文案：`删除记录成功`。

取消分享：

- 确认文案：`确定要取消这个分享吗？取消后接收人和分享链接都无法继续访问。`
- 成功文案：`取消分享成功`。

## Testing Strategy

### Backend Tests

- `ShareLinkServiceTest`
  - 取消分享后 `resolveShare` 抛出 `分享已取消`。
  - 删除记录仅设置 `hiddenByCreator`，不设置 `cancelled`。
  - 列表查询过滤已删除记录。
  - 用户分享列表能生成 `recipientDisplayText`。

- `ShareControllerTest`
  - `/api/share/delete` 调用删除记录语义。
  - `/api/share/cancel` 调用取消分享语义。

### Frontend Tests

如果已有适合 helper 的测试入口，则抽取分享内容展示 helper，覆盖：

- 单文件分享生成内容项。
- 目录/批量分享取前 3 个展示。
- 超过 3 个时生成 `+N`。
- 路径 tooltip 使用 bucket 和 objectName。
- `USER` 类型分享方式拼接接收人文本。

### Manual Acceptance

- 我的分享列表中能直接看到分享内容列。
- 标签悬停能看到路径。
- 分享到用户显示具体接收人。
- 删除记录后列表不显示该记录，但接收人仍能打开。
- 取消分享后接收人打开提示“分享已取消”。
- 旧分享记录升级后仍显示且可访问。

## Risks

- 大量分享项如果同时加载内容会增加接口请求数。第一版采用异步加载，必要时后续可改为后端列表聚合摘要。
- 接收用户展示依赖站内信记录。如果历史站内信缺失，只能保底显示“分享到用户”。
- 删除记录语义改变会影响用户对原按钮的理解，因此必须修改 tooltip 和确认文案。

## Acceptance Criteria

- `分享内容` 出现在主表指定位置。
- 分享内容标签悬停能显示存放路径。
- `分享到用户` 能展示具体接收人。
- 删除记录和取消分享两个功能都可用且语义独立。
- 取消分享后所有分享访问入口失效。
- 版本号更新到 `1.8.1` 且补充版本说明。
